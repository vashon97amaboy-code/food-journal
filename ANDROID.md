# Сима — Android-приложение (первый этап)

Основная версия на GitHub Pages остаётся PWA. Нативная версия использует **Capacitor 8** и те же HTML/JS-экраны.

## Сборка на компьютере

Нужны Node.js, Android Studio и Android SDK.

1. `npm install`
2. `npm run android:init` — создаёт папку `android/` (в первый раз)
3. `npm run android:open` — открывает Android Studio
4. После изменений в веб-коде: `npm run android:sync` и затем запуск через Android Studio

## Камера без фотографий в галерее

В нативном приложении экран штрихкода и фото КБЖУ вызывают `@capacitor/camera` с `saveToGallery:false`, `source:'CAMERA'` и `resultType:'uri'`. Результат считывается во временный Blob для распознавания; приложение **не копирует его в галерею**. Системная камера отвечает за автофокус. На отдельных устройствах стороннее приложение камеры может вести себя иначе — протестировать на Android обязательно.

В браузере/PWA продолжает работать существующий вызов системной камеры через `<input type=file capture>`: браузер не может запретить сторонней камере сохранять фото.

## Технические замечания

- Для Android используется отдельная сборка `www/`, а сервис-воркер PWA при нативном запуске не регистрируется.
- После создания папки `android/` надо добавить её в Git-репозиторий из Android Studio / Git; до первого запуска исходников нативного проекта в репозитории нет.
- APK собирается автоматически в GitHub Actions, а камера уже проверена на Android: автофокус работает, снимки не появляются в галерее.
- Android-сборка включает библиотеку распознавания штрихкодов локально; поиск товаров в Open Food Facts и распознавание этикеток через Tesseract (пока CDN) требуют подключения при первом использовании.
- Тестовая подпись хранится в кеше GitHub Actions. Если кеш подписи пропадёт, сборка специально остановится вместо создания APK с новым ключом. Для постоянных релизов нужно перенести ключ в защищённые GitHub Secrets и управлять им как постоянным ключом выпуска.
- Данные дневника пока локальные в WebView, не автоматически перенесённые из PWA: перед сменой версии сохрани резервную копию JSON и восстанови её в Android-приложении.
