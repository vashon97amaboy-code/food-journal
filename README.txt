# Дневник питания — публикация на GitHub Pages

1. Создайте публичный репозиторий на github.com, например `food-journal`.
2. Откройте репозиторий → Add file → Upload files. Загрузите из архива файлы `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` в корень репозитория (не сам ZIP). Нажмите Commit changes.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, Folder: /(root) → Save.
4. Дождитесь появления ссылки вида `https://USERNAME.github.io/food-journal/`.
5. Android: открыть ссылку в Chrome → меню ⋮ → Добавить на главный экран / Установить приложение.
6. iPhone: открыть ссылку в Safari → Поделиться → На экран «Домой».

ВАЖНО: не публикуйте реальные данные о здоровье, ключи API или личные файлы в репозитории. Дневник сохраняется только локально в браузере каждого устройства, без синхронизации. Удаление данных сайта может стереть записи. Для резервного копирования пока нет функции экспорта.

Камера требует HTTPS и разрешения; библиотека сканирования загружается через интернет. Поиск штрихкода обращается к Open Food Facts, а QR и Data Matrix не гарантируют получение информации о КБЖУ. Функции ещё требуют проверки на реальных телефонах.
